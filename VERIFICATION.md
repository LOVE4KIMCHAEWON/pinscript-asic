# PinScript verification report

The executed results, exact tested source commit, tool versions, SHA-256
checksums and Yosys cell counts are generated by CI in
[reports/latest.md](reports/latest.md) and [reports/summary.json](reports/summary.json).
The JUnit files and [synthesis log](reports/yosys.log) are committed alongside
the netlist. CI generates this evidence only after all validation steps pass.

## Validation performed

- Assemble all five firmware programs and compare the regenerated binaries,
  hex files and listings with the committed files.
- Run 16 Python reference-model tests. These include all 256 UART transmit
  bytes and all 256 SPI receive bytes with independent transmit data, ISA
  edge cases, assembler rejection, UART RX and I2C decisions.
- Run 20 Cocotb tests against the actual RTL through its external ports.
- Run Yosys hierarchy validation, generic synthesis and `check -assert`.
- Run the same 20 Cocotb tests against the generated Verilog netlist.
- Run Verilator structural lint and review the warning categories.

The tested scenarios include UART TX/RX, SPI Mode 0 TX/full duplex, I2C
open-drain writes, independent A/B accumulators, clock-by-clock randomized
ISA comparisons, execution pause/resume, program-memory and PC wraparound,
malformed SPI frames, HALT/RUN state changes, and reset retaining RAM.

Additional physical-pin models check I2C START/STOP and ACK/ACK, address NACK
and data NACK; SPI setup, high/low periods, CS framing, and receive patterns
00/ff/a5/5a; UART TX idle pull-up behavior and six 8N1 payloads; and 54 UART
RX payload/bit-period/start-phase combinations. Loader SPI edges are also
varied relative to the system clock while preserving conservative timing.

Native Windows Icarus 14.0 development build plus Cocotb 2.0.1 independently
passed all 20 RTL tests. GitHub Actions uses Ubuntu's tool versions recorded
in the generated report for the reproducible RTL and generic-netlist runs.

## Fixes made during import and verification

1. Use `CURDIR` for simulator sources so invoking `make -C test` resolves
   files correctly. Invoke the synthesis script with `bash`, preserving
   functionality when ZIP extraction lacks executable permissions.
2. Configure the Python cache for `requirements-test.txt`. The first CI run
   stopped during setup because the default cache search expected a file
   named `requirements.txt` or `pyproject.toml`; no passing result is claimed
   for that run.
3. Preload idle-high UART TX and SPI CS output values before enabling their
   drivers. The original DIR-before-OUT sequence created an unwanted
   one-clock low pulse. External-pin tests now reject that startup pulse.
4. Correct the MOSI synchronization description: the sampler uses stage 1,
   while the unused third MOSI register is optimized away.
5. Pin Python dependencies, preserve independent RTL/generic JUnit reports,
   check regenerated firmware, record source/firmware hashes, and commit
   artifacts only after the validation suite completes successfully.
6. Preserve the original GDS workflow in `docs/templates/gds.yaml.disabled`;
   no GDS or place-and-route job is active.

The RTL datapath and SPI-loader logic from v2 required no functional change
for the exercised scenarios. The protocol fixes change firmware startup
ordering without changing instruction counts or serial bit periods.

## Warnings reviewed

Verilator reports the Tiny Tapeout source filename differing from the module
name, and intentionally unused bits: MOSI synchronization stage 2,
instruction bit 11, and SPI shift bit 7. These are documented/reserved or
optimized away. CI permits those two warning categories and fails report
generation on a newly introduced category. Yosys structural checks must pass.

## Scope and remaining physical work

`build/netlist_generic.v` and `.json` are real Yosys-generated generic logic
and flip-flop netlists. The current Yosys 0.33 flow reports 3,572 generic
cells, including 1,516 mux cells, with no remaining memory objects or
processes. Generic cell count does not establish IHP cell area or 6x4 fit.

This delivery does not perform IHP Liberty/PDK mapping, static timing,
clock-tree synthesis, floorplanning, placement, routing, GDS, DRC/LVS, FPGA
validation or silicon testing. The nominal 12 MHz clock is a design target;
no achieved Fmax is claimed. Synchronous simulation does not establish
metastability MTBF, electrical rise times, or asynchronous reset-release
performance. Passing RTL/netlist regression covers the tested scenarios and
is not a formal equivalence proof.

UART RX remains one-shot without stop-bit validation/majority voting; SPI
full duplex is one byte without a FIFO; I2C lacks clock stretching,
arbitration, recovery and repeated START. External compatible pull-ups and
I/O voltage handling remain necessary.
